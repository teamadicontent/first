# Tagged Template Index

Compact index of all 250 templates in `template-library.md`. Read this first when picking templates; open the full skeleton in the library only for the ones you pick (search for `## <ID> —`).

## Tags

- **spec**: can this template be used for a spec post written from public research?
  - `go`: writable from public research plus the prospect's domain (their business, audience, public stances, public stats). Still needs sources for any fact.
  - `found`: usable **only if research surfaced the exact item in "Needs"** (a sourced story, a published client result, a public metric). If it isn't sourced, don't use the template.
  - `skip`: promotional mechanics (launches, events, giveaways, lead magnets, testimonials, hiring, ads). They depend on the prospect's real offer, so they aren't used for spec posts.
- **type**: story · proof (their own result) · case (client result) · about (intro/personal facts) · contrarian · insight (reframe/observation) · educational (how-to, mistakes, frameworks) · news (news/prediction/trend) · curation (books, tools, other people's stories) · promo
- **tone**: match to the prospect's voice. warm (reflective, personal) · analytical (data, process) · bold (provocative) · punchy (short lines, rhythm) · playful (humour, memes)
- **Tier** (from the library): A = needs a personal narrative · B = needs verified specifics · C = domain expertise only

Selection rule: pick 5–10 templates with mixed types (at most 2 of any type), matched to tone. With no sourced story, pick only from `go` rows plus `found` rows whose "Needs" research actually covered. Avoid picking two templates the library's **Note** line marks as echoes of each other.
